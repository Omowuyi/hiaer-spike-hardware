# Software for v12b

The software used with this bitstream (unchanged from v12b; the hardware suite flashes v12c by default) is on branch v12b_tested in hs_bridge, hs_api and connectome_utils
(github.com/Integrated-Systems-Neuroengineering). hs_api/hardware_suite runs the complete hardware suite.
state/ records each repository's branch, commit and uncommitted changes at the time of the v12c hardware tests.
